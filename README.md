# 🎵 AI Music Recommendation System

An AI-powered Indian music recommendation system built using Genetic Algorithms and Streamlit.

## Features

- Personalized song recommendations
- Real Spotify music dataset
- Indian multilingual songs
- Real album artwork
- Spotify song links
- Genetic Algorithm optimization
- Interactive Streamlit UI
- Fitness convergence visualization

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- DEAP
- Genetic Algorithms

## Dataset

Spotify Indian music dataset containing:
- Hindi songs
- Tamil songs
- Telugu songs
- Punjabi songs
- Audio features from Spotify
